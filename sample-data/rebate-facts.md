# Rebate facts (the only ones the preview may use)

Checked **28 October 2026** by reading the Clean Energy Regulator (CER) pages directly. In the full system the Forecast agent re-reads these pages and keeps this file current; a message never goes out on a fact more than 30 days old.

| ID | Fact | Source |
|---|---|---|
| F1 | **Home batteries:** certificates per kWh of usable capacity, by installation date. 2026 May to Dec: **6.8**. 2027 Jan to Jun: **5.7**. 2027 Jul to Dec: **5.2**. So the next step down is for batteries installed from **1 January 2027**. | CER, [Solar batteries](https://cer.gov.au/schemes/renewable-energy-target/small-scale-renewable-energy-scheme/small-scale-renewable-energy-systems/solar-batteries) and [Calculate STC entitlements](https://cer.gov.au/schemes/renewable-energy-target/small-scale-renewable-energy-scheme/small-scale-technology-certificates/calculate-small-scale-technology-certificate-entitlements) |
| F2 | **Since 1 May 2026** the battery rate applies in full to the first 14 kWh of usable capacity, at 60% for the part above 14 kWh up to 28 kWh, and at 15% for the part above 28 kWh up to 50 kWh. | Same CER pages |
| F3 | **The installation date decides the rebate**, not the date a contract is signed. | CER media release, [Battery rebates are changing 1 May 2026](https://cer.gov.au/news-and-media/media/2026/march/battery-rebates-are-changing-1-may-2026), 18 March 2026 |
| F4 | **Rooftop solar:** the deeming period is **5 years** for systems installed in 2026 and **4 years** for 2027, which reduces how many certificates the same system can create. | CER, [Deeming period decline](https://cer.gov.au/RET/Scheme-participants-and-industry/Agents-and-installers/Deeming-period-decline) |
| F5 | **No dollar figures.** The dollar value of a certificate isn't set by these pages, so a message never states one. A dollar figure only ever appears inside a written quote for one named customer. | TMEC's rule |

Eligibility rules apply; the line we use is "eligibility rules apply and I'll check yours".
