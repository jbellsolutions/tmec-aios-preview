# Your memory

The Chief of Staff writes here:

- `daily/<date>.md`: one note per day, with the morning brief at the top.
- `big-list.md`: your big list for Session 1, in your own words.

To see it as a linked notebook, open this `vault` folder in [Obsidian](https://obsidian.md) (free): Open folder as vault. In the full system this memory grows a note for every day, customer, partner and decision.
